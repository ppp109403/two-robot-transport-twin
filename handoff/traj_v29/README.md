**v2 와 사실상 같은 성능인데 90 도 문제가 없습니다.** 그리고 600 iteration 만에

### 무엇을 바꿔서 이렇게 됐나

```
차체 참조(MPC 모티브) 를 버림   <- 가장 큰 것
90 도 규약                     막대가 실물 기준으로 정렬됨
페이로드 (배터리 8.0 + 드라이버 0.5 kg)
학습 궤적을 실측 (v, omega) 이어붙이기 생성본으로
목표 높이 0.50 ~ 0.60
차체 안정을 **참조 없이** — 각가속도·지령변화율·각속도·후진 벌점
```

차체 참조를 조일수록 EE 가 나빠지는 것이 여섯 판에서 일관됐습니다
(v2 8.6 mm -> v12 13.9 -> v17 31.4 -> v28 41.7 -> v24 105.1). 차동구동은 옆으로 못
가므로, 팔이 좋은 자세를 만들려면 **차체가 자리를 옮겨야** 하는데 참조가 그것을
막습니다.

**58 차원 판들보다 훨씬 안정적**입니다. 실기 손 떨림이 줄어들 가능성이 높습니다.

다만 떨림 스펙트럼은 여전히 저주파입니다::

**저역통과 필터(브리지 ``follow_gain`` 낮추기) 는 여전히 권하지 않습니다** — 고주파
잡음이 아니라 되먹임 성분이라 위상여유만 깎입니다.

플래너 여유를 크게 잡아야 합니다. 방 안에서 먼저 확인해 주세요.
